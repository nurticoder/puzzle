 # Puzzle Game

This project is a puzzle game designed to challenge players with logical problems and increasingly difficult tasks. Players must observe the available information, identify patterns, and choose the correct actions to complete each puzzle.

## Goals

- Complete each puzzle successfully.
- Improve logical reasoning and problem-solving skills.
- Recognise patterns and make careful decisions.
- Progress through challenges with as few mistakes as possible.

## Advantages

- Encourages critical and analytical thinking.
- Provides an interactive way to practise problem solving.
- Offers a gradual challenge suitable for different skill levels.
- Gives immediate feedback, helping players learn from mistakes.
- Can be played at the player's own pace.

## How to Play

1. Start a puzzle from the game menu.
2. Read the instructions and examine the available clues.
3. Select or arrange the correct pieces, answers, or moves.
4. Submit the solution and use the feedback to improve.
5. Continue to the next challenge after solving the puzzle.

## Project

This game was created as part of the COMP1117 project. Its focus is to combine clear gameplay with engaging puzzles that reward observation, planning, and persistence.
